# Caustica demo film

The delivered film is 240 seconds, 7,200 frames, 1920×1080 at 30 fps, with H264/yuv420p video and stereo AAC audio. `CausticaDemo` is the editable Remotion composition. `src/demo-shots.json` owns the 31-shot timeline for both rendering engines.

The local master uses native Remotion graphic plates, all 7,200 states exported from the authored easing/Seam functions, and OpenCV/FFmpeg composition of genuine browser recordings. Software Remotion video rendering was too slow on this host. No half-resolution draft frames were enlarged.

The film distinguishes exact-snapshot demonstrations from historical Kane recordings. Actual local receipts, assertions, source diff and rejection results supply the evidence excerpts. The real Codex subprocess failed authentication; the accepted repair uses the explicitly labeled developer-mediated mode. The final claim covers this contract and independent control on an honest local host.

From this directory, with the resolved ignored `../demo-studio.config.json` and local captured/licensed media available:

```sh
npm run check
npm run lint
npm run graphics
npm run render
npm run qa
```

`npm run studio` opens `http://localhost:3417/CausticaDemo`. `npm run render:remotion` renders the complete composition directly. `npm run motion` refreshes exported states after timeline edits. Hybrid recovery accepts only complete chunks whose source, renderer code and motion digests match.

Final artifacts are `output/Caustica_Demo_Final.mp4`, `output/Caustica_Demo_Poster.png`, and `output/Caustica_Demo_Final.srt`. Captions remain a sidecar. There are no narrative corner labels, edge captions, badges, watermarks or time overlays. Actual product text remains inside centered footage panes.
